# Loja Virtual de Cupcakes — Projeto Integrador Transdisciplinar

Aplicação web responsiva de e-commerce para uma loja de cupcakes gourmet: vitrine virtual, carrinho, pedido eletrônico, pagamento e entrega, além de um painel administrativo para produtos, estoque e pedidos.

Projeto desenvolvido nas disciplinas **Projeto Integrador Transdisciplinar em Engenharia de Software I e II** (Cruzeiro do Sul Virtual).

> Status: em desenvolvimento.

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `docs/situacao-1-planejamento` | Documentação revisada do PIT I: escopo, histórias de usuário, backlog, UML, IHC (wireframes, mockups, mapas) e modelagem de dados |
| `docs/situacao-2-desenvolvimento` | Arquitetura, decisões técnicas e manual de uso |
| `docs/situacao-3-validacao` | Plano e evidências de testes (verificação e validação), formulário de teste, fichas dos testadores e laudo de qualidade |
| `database` | Scripts DDL, seed e dicionário de dados |
| `src` | Código-fonte da aplicação (em breve) |

## Stack (proposta)

- **Front-end e back-end:** Next.js (TypeScript), organizado em camadas MVC
- **Banco de dados:** PostgreSQL
- **Testes:** unitários e de integração + testes end-to-end
- **Hospedagem:** Vercel
