# Fichas dos Testadores

Transcrição das respostas recebidas pelo [formulário de teste](03-formulario-teste-usuarios.md). Os cinco primeiros campos de cada ficha são os mesmos do template oficial da atividade. Os campos extras registram o tratamento dado a cada apontamento.

> Preencher **somente** com respostas reais. Não editar o conteúdo escrito pelo testador: comentários do desenvolvedor vão apenas em "Ação tomada".

**Gravidade:** Bloqueante · Alta · Média · Baixa · Sugestão
**Ação tomada:** Corrigido · Melhoria incorporada · Não pertinente (justificar) · Pendente (justificar)
